# Personal Portfolio Website

A personal portfolio website built to showcase my software development projects and skills.

The website includes a selection of my projects, an About Me section, links to my GitHub and LinkedIn profiles, and a functional contact form that sends messages directly to my email.

## Features

- Responsive personal portfolio website
- Project showcase with links to GitHub repositories
- About Me section
- Links to GitHub and LinkedIn
- Functional contact form
- Email notifications using SMTP
- Success message after sending a message
- Environment variables for sensitive credentials

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SMTP
- python-dotenv

## Running the Project

1. Clone the repository:

```bash
git clone https://github.com/gustavodev6331/Website.git
```

2. Navigate to the project folder

```bash
cd Website
```

3. Create a virtual environment

```bash
python -m venv .venv
source .venv/bin/activate
```

4. Install the dependencies

```bash
pip install -r requirements.txt
```

5. Create a .env file in the root directory:

```bash
MY_EMAIL=your-email
MY_PASSWORD=your-gmail-app-password
SECRET_KEY=your-secret-key
```

6. Run the application

```bash
python server.py
```


The application will be available at:

```text
http://127.0.0.1:5000
```
